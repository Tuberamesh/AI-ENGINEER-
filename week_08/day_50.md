# DAY 50 — Understanding AI Agents

## 1. What is an AI Agent?
An AI agent is a system that uses an LLM to understand goals,
select tools, execute actions, observe results and complete tasks.

## 2. LLM vs AI Agent
- LLM: Understands and generates language.
- AI Agent: Uses an LLM and tools to perform tasks.

## 3. LLM + Tools
Tools provide external capabilities:
- Calculator
- Python execution
- Web search
- Database
- File operations
- APIs

## 4. Why Agents?
Agents automate multi-step workflows requiring decisions
and external actions.

## 7. Important Understanding
- An LLM is not automatically an agent.
- An agent can use one or multiple tools.
- The application executes tools.
- The LLM interprets tool results.
- Agents need stopping conditions and safety controls.
